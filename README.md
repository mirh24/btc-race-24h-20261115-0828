A capitulation-reversal trading bot for cbBTC/USDC on 1-minute bars, long only. It sits in cash and buys full size only when the price made a new 240-bar low within the last 30 bars and rebounded at least 1.5% above it, exiting at +3% / -1.5%. Dev-window net PnL +$30.37.

## Run it

```sh
python3 -P -s main.py
```
